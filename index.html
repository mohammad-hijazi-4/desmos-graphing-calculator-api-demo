Desmos API Demo

Interactive Graphing Calculator

This repository does not contain an API key. Enter your own Desmos API key locally in the browser to run the demo.

Enter API key locally

Get a key from Desmos API. This demo does not store it; your browser sends it to Desmos to load the API.

Try a one-minute graphing tour

  1. Load the calculator, then select Intersection demo. Click the gray points at (-1, 1) and (3, 9).
  2. Select Clear, then add Circle and Inequality to compare graph types.
  3. Select Download PNG to save the graph you see.
